# Declaración de Uso de Inteligencia Artificial Generativa

Durante la elaboración de este documento, se utilizaron herramientas como Perplexity para la búsqueda de referencias, y ChatGPT y Gemini como recursos de apoyo durante las distintas etapas de elaboración de los entregables.

Las herramientas fueron utilizadas principalmente para realizar consultas preliminares, explorar referencias y fuentes potenciales, y aclarar conceptos y contenidos teóricos mediante explicaciones, referencias a papers y libros, así como ejemplos. Asimismo, se utilizaron para explorar conexiones con aplicaciones de terceros entre el ERP seleccionado (Odoo 18) y el módulo de Contabilidad, el cual es de pago, por lo que se buscaron y consultaron otras alternativas disponibles.

También se utilizaron como apoyo para la revisión de la redacción, principalmente en aspectos relacionados con la claridad, fluidez, cohesión y selección de conectores, así como para sugerir alternativas de formulación cuando fue necesario.
